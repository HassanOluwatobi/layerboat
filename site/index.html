Skip the SVG export, the Illustrator cleanup and the XD workaround.

Those detours exist because a normal import hands you a flat picture, grey gradients or text turned into outlines. LayerBoat rebuilds your design with each app's own layers, so you pick up where the design left off.

Your Figma text lands in After Effects as text you can still edit.

Send a frame and you get live text, shape layers and your images, named exactly as they were in Figma and sitting exactly where they were. Gradients, masks, dashed strokes and rounded corners come along too. No reference overlay and no nudging layers into place.

Updated from Figma. Keyframes kept.

Send layers from Illustrator to Figma and back. They come back as shapes, not flat images.

Pasting from Illustrator often gives Figma a flat image, outlined text or broken paths. Going the other way turns your Figma text into outlines. LayerBoat moves groups, masks, gradients and live text in both directions and keeps your layer names. After Effects comps can go to either app too.

Set it up once.

A few steps, about five minutes. The installer in step two sets up every app for you.

  1. Download and unzipYou get a folder called LayerBoat. Keep it until you've finished.
  2. After Effects
    Run the installerGo to File › Scripts › Run Script File and pick Install LayerBoat.jsx. The panel opens right away.
  3. Figma
    Add the pluginGo to Plugins › Development › Import plugin from manifest. The installer shows you which file to pick.
  4. Illustrator
    Open the panelGo to File › Scripts › Other Script and pick LayerBoat Panel.jsx from the folder the installer shows.

Using Photoshop? Restart it once after installing. LayerBoat is then in File › Scripts › LayerBoat - Send to After Effects.

In After Effects, use Run Script File. The option just below it, Install ScriptUI Panel, is a different one and won't set LayerBoat up.

Questions.

Is it really free?

Yes. There's no account, no trial and no paid version. The code is MIT licensed, so anyone can read it, change it or build on it.

Does it upload my designs anywhere?

No. Your designs move between apps through a helper running on your own computer. Nothing is sent online.

Which versions does it work with?

Recent versions of After Effects, Illustrator and Photoshop, and the Figma desktop app. Text with mixed styles in one box needs After Effects 2024.3 or newer.

Does it work on Windows?

Yes. LayerBoat works on Mac and Windows.

Nothing arrives in After Effects. What do I check?

Make sure Receive live from Figma is ticked in the panel, and that Settings › Scripting & Expressions › Allow Scripts to Write Files and Access Network is on. You can also click Copy instead in the Figma plugin, then Paste from Figma in After Effects.

How do I remove it?

Run Uninstall LayerBoat.jsx from the download the same way you ran the installer. Then remove the plugin in Figma under Plugins › Development › Manage plugins in development.

I found a bug.

Open an issue on GitHub. Say which apps you used, what you sent and what came out. A screenshot helps a lot.
