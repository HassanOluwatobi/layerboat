Download LayerBoat

LayerBoat runs on a Mac or PC. Open this page there to install it.

For Mac and Windows · After Effects, Illustrator and Figma

What it does

Figma to After Effects

Send a frame and it arrives as shape layers and editable text, ready to animate.

After Effects to Figma

Send a comp back and keep working on it in Figma, layers and all.

Illustrator, both ways

Move artwork between Illustrator, After Effects and Figma from a small panel.

Install in three steps

  1. Download and unzip.Click the button above. You get a folder called LayerBoat.
  2. Run the installer in After Effects.Go to File › Scripts › Run Script File and pick Install LayerBoat.jsx. The panel opens right away. Later you find it under Window › LayerBoat.jsx.
  3. Add the Figma plugin.In Figma, go to Plugins › Development › Import plugin from manifest and pick manifest.json inside the Figma Plugin folder.

For Illustrator, go to File › Scripts › Other Script and pick LayerBoat Panel.jsx. If After Effects says scripts can't write files, turn on Settings › Scripting & Expressions › Allow Scripts to Write Files and Access Network and run the installer again.
