Move layers between Figma, Illustrator and After Effects, both ways. Real shapes, live text, nothing flattened.

## Install

1. Download **LayerBoat 1.12.3.zip** below and unzip it.
2. Open After Effects. Go to File > Scripts > Run Script File and pick **Install LayerBoat.jsx**.
3. Restart After Effects. Open the panel from Window > LayerBoat.jsx.
4. In Figma, go to Plugins > Development > Import plugin from manifest and pick **Figma Plugin/manifest.json**.

The README inside the zip covers Illustrator and troubleshooting.

Works on Mac. Windows support is built in and waiting on its first real-world test. If you try it on Windows, please open an issue and tell us how it went.
